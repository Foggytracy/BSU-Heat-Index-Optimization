# BSU-Heat-Index-Optimization

# Optimal Academic Year Selection for Bulacan State University

## Project Description
This research uses a **Seasonal Average Forecast** and a **Sliding Window Optimization** algorithm to identify the 10-month period with the lowest Heat Index (HI) exposure.

## How to Run
1. Open MATLAB.
2. Run `src/main_optimization.m`.
3. View the generated plot in the `/results` folder.
